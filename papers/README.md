# Expository notes

`entropy/main.tex` is a retained educational note on finite-alphabet
cross-entropy, boundary paths, and softmax gradients. It is not presented as
original research and has no public PDF attachment.

`entropy/verify_revision.py` checks the revised note's numerical formulas.
`entropy/probe_entropy.py` preserves counterexample and numerical probes from
the earlier audit. Passing numerical checks does not prove universal claims.

The orthogonality, manifold, painting-arithmetic, and recursive-AMC drafts,
their PDF copies, the superseded entropy audit reports, and the SimO₂
experiment plan were withdrawn from the working tree. Their history remains
in git. Experiment code and saved results elsewhere in the repository remain
available; retaining them does not certify the withdrawn drafts' claims.

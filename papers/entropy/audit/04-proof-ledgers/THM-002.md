# THM-002 — Theorem 6 — uniform-smoothing asymptotic

**Statement:** For (q^{(\varepsilon)}=(1-\varepsilon)q+\varepsilon u) on an n-symbol alphabet,

\[
H(p,q^{(\varepsilon)})=S(-\log\varepsilon)+S\log n+C_{p,q}+O(\varepsilon).
\]

**Verdict:** Verified under additional assumptions
**Confidence:** High

## Step ledger

| Step | Claim | Justification given | Assumptions used | Validity | Issue |
|---|---|---|---|---|---|
| 1 | For x in V, (q_x^{\varepsilon}=\varepsilon/n) | q_x=0 and u_x=1/n | Uniform smoothing | Valid | None |
| 2 | Violating terms sum exactly to (S(-\log\varepsilon+\log n)) | Finite sum | Fixed log base | Valid | None |
| 3 | For x not in V, terms converge to (-p_x\log q_x) | Pointwise continuity | If p_x>0 then q_x>0; if p_x=0 term is zero | Valid | The p=q=0 case should be separated explicitly |
| 4 | The nonviolating error is (O(\varepsilon)) | Asserted | Finite X; fixed p,q; positive relevant q_x | Valid but underexplained | Needs Taylor/MVT bound |

## Findings

- **Missing steps:** State that for each p_x>0,q_x>0, Taylor's theorem gives

  \[
  -p_x\log((1-\varepsilon)q_x+\varepsilon/n)
  =-p_x\log q_x-\varepsilon p_x(1/(nq_x)-1)+O(\varepsilon^2).
  \]
  Finite summation yields the theorem.
- **Hidden assumptions:** p,q fixed as epsilon tends to zero; (0<\varepsilon<1); fixed log base; O-constant not uniform over q near additional zeros.
- **Exact claim proved?** Yes under those assumptions.
- **Repair:** Add the Taylor line and define the normalized rate. Replace Figure 1, which is not generated by valid examples.
- **Downstream consequences:** The valid result supports the finite-alphabet note but none of the contrastive-learning claims.
